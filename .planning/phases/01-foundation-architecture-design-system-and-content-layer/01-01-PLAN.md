<task type="auto">
  <name>Task 2: Define monochrome/editorial design tokens and self-hosted typography</name>
  <files>src/app/globals.css, src/app/layout.tsx</files>
  <action>
    Replace Tailwind's default-generated `globals.css` content with a project-owned `@theme` block defining a **semantic, monochrome/neutral palette** and a **bold editorial type scale**, per MOTION-03 and Pitfall 3 from research (raw Tailwind defaults like `text-gray-500` must not be the "path of least resistance" — name tokens so there's an obvious right class to reach for).

    Example structure (adapt exact values, but keep the semantic naming pattern):
    ```css
    @import "tailwindcss";

    @theme {
      /* Monochrome/neutral palette — semantic names, not raw scale re-exports */
      --color-ink: #0a0a0a;
      --color-ink-muted: #4a4a4a;
      --color-paper: #fafaf9;
      --color-paper-dim: #f0efec;
      --color-line: #d9d7d2;

      /* Editorial type scale */
      --font-display: var(--font-display-family);
      --font-body: var(--font-body-family);
      --text-display-xl: 5rem;
      --text-display-lg: 3.5rem;
      --text-display-md: 2.5rem;
      --text-body-lg: 1.25rem;
      --text-body: 1rem;
    }
    ```

    Select and load a strong free editorial typeface pairing via `next/font/google` in `src/app/layout.tsx` (research flags this as an open design decision with a placeholder-acceptable default — choose one now, e.g. a bold grotesk/serif display pairing, swappable later since `next/font` usage is centralized here). Example:
    ```typescript
    import { Fraunces, Inter } from "next/font/google";

    const display = Fraunces({ subsets: ["latin"], variable: "--font-display-family", display: "swap" });
    const body = Inter({ subsets: ["latin"], variable: "--font-body-family", display: "swap" });
    ```
    Apply both font variable classNames to the root `<html>` or `<body>` element. Never use a Google Fonts `<link>` tag or CSS `@import` — `next/font` only (per PITFALLS.md).

    Do not use raw Tailwind default color utilities (`text-gray-*`, `bg-slate-*`, etc.) anywhere in this plan's own files — reach for the semantic tokens defined here.
  </action>
  <verify>`npm run dev`, load the root page, inspect computed styles in DevTools — confirm `--color-ink`, `--color-paper`, and font-family custom properties resolve to the chosen values, not Tailwind defaults. `grep -rn "text-gray-\|bg-slate-\|text-zinc-" src/app` returns no matches.</verify>
  <done>`globals.css` contains a single `@theme` block defining the full monochrome palette + editorial type scale; both display and body typefaces load via `next/font/google` with zero layout-shift (`display: "swap"`, no external `<link>`); fonts are visibly applied on the root page.</done>
</task>
