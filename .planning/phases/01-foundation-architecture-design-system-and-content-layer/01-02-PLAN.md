  <name>Task 1: Install GSAP/Lenis and build the Reveal primitive with reduced-motion built in</name>
  <files>package.json, src/lib/gsap.ts, src/components/motion/Reveal.tsx</files>
  <action>
    Install the motion stack:
    ```bash
    npm install gsap @gsap/react lenis
    ```
    Verify installed major versions roughly match research (`gsap` 3.15.x, `lenis` 1.3.x) via `npm list gsap lenis @gsap/react` — if versions differ meaningfully, note it in the SUMMARY but proceed (research flags these ship frequently).

    Create `src/lib/gsap.ts` — a single client-only module that registers `ScrollTrigger` once:
    ```typescript
    "use client";
    import gsap from "gsap";
    import { ScrollTrigger } from "gsap/ScrollTrigger";

    if (typeof window !== "undefined") {
      gsap.registerPlugin(ScrollTrigger);
    }

    export { gsap, ScrollTrigger };
    ```
    Import GSAP from this module everywhere in the project going forward (never import `gsap`/`ScrollTrigger` directly in component files) — this is what prevents Pitfall (duplicate plugin registration across routes) from research.

    Build `src/components/motion/Reveal.tsx` exactly per Pattern 1 in `01-RESEARCH.md`: a `"use client"` component using `@gsap/react`'s `useGSAP()` hook, with `gsap.matchMedia()` branching on `(prefers-reduced-motion: reduce)` vs `(prefers-reduced-motion: no-preference)`. The reduced-motion branch must set final state instantly (`gsap.set(ref.current, { opacity: 1, y: 0 })`) — not a "faster" version of the same animation. The no-preference branch does the real `gsap.from(...)` scroll-triggered reveal. Accept `children` and minimal generic props (e.g. `y` offset) — this component must never import or reference domain types (`Project`, `Service`, etc.).

    Follow the exact cleanup structure from Pattern 1: `mm.revert()` inside `useGSAP`'s own returned cleanup, not inside the `matchMedia` handler's returned function (Pitfall 4 in research — don't confuse the two cleanup layers).
  </action>
  <verify>`npm list gsap @gsap/react lenis` shows all three installed. `grep -n "matchMedia" src/components/motion/Reveal.tsx` matches. Build a temporary test usage on any page, toggle macOS System Settings → Accessibility → Display → Reduce Motion (or Chrome DevTools Rendering tab → emulate `prefers-reduced-motion: reduce`), reload — content appears instantly with no transform/opacity animation.</verify>
  <done>`Reveal.tsx` exists, is fully content-agnostic (no domain-specific props/types), and demonstrably shows static content (not a simplified animation) when OS reduce-motion is on, and a scroll-triggered fade/slide reveal when it's off.</done>
