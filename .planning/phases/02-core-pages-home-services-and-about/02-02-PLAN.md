<objective>
Build the full homepage (HOME-01, HOME-02), replacing Phase 1's intentional skeleton, and resolve the "View Projects" CTA's target route with a minimal placeholder `/work` page.

Purpose: The homepage is the site's first impression and the primary demonstration of "Awwwards-grade" brand tone — a cinematic scroll-triggered hero sequence composed entirely from Phase 1 + 02-01 primitives (TextReveal, Reveal, MagneticButton, ScrollTrigger, Lenis), no WebGL/Three.js. `nav` already links to `/work` (see `layout.tsx`) with no page behind it yet; this plan resolves that gap with a decision documented below rather than leaving HOME-02's CTA target ambiguous.

**Decision (resolves 02-RESEARCH.md Open Question 3):** "View Projects" links to `/work`. Phase 2 ships a minimal, real (not 404) placeholder page there — a heading, one line of copy ("Full project archive coming soon" or similar), and an Enquire CTA — so the homepage CTA has a real destination. Phase 3 fully replaces this route's content with the real filterable portfolio gallery (PORT-01); this plan does not attempt to build any gallery/filtering logic.

**Decorative direction:** Storey Architecture's reference site uses small decorative line-art (pencil/ruler-style icons) as an ambient brand texture, not content. This plan adds one equivalent for Stoneage: a subtle architectural blueprint/floor-plan line-art accent (`BlueprintAccent`), used once as a low-opacity background layer behind the Hero — reinforcing "specialist building contractor" positioning without competing with the headline for attention.

Output: `components/sections/Hero.tsx`, `components/decorative/BlueprintAccent.tsx`, a fully composed `app/(marketing)/page.tsx`, and `app/(marketing)/work/page.tsx`.
