  <files>src/components/motion/TextReveal.tsx</files>
  <action>
Rewrite the `noPreference`/`reduceMotion` branch inside `TextReveal`'s `mm.add(...)` callback so the tween is built and returned from `SplitText.create()`'s `onSplit(self)` callback, per `02-RESEARCH.md` Topic 1's verbatim-sourced code example:

```typescript
SplitText.create(ref.current, {
  type: "words",
  mask: "words",
  autoSplit: true,
  aria: "auto",
  onSplit(self) {
    if (reduceMotion) {
      gsap.set(self.words, { autoAlpha: 1, y: 0 });
      return; // no tween to return under reduced motion
    }
    return gsap.from(self.words, {
      y: "100%",
      autoAlpha: 0,
      duration: 0.8,
      stagger: 0.04,
      ease: "power3.out",
      scrollTrigger: {
        trigger: ref.current,
        start: "top 85%",
      },
    });
  },
});
```

Key points to preserve from the current implementation:
- Keep the existing `gsap.matchMedia()` outer structure (`reduceMotion`/`noPreference` conditions) exactly as-is — only the *body* of what happens once split, changes.
- `SplitText.create()` itself must still be called unconditionally (both branches need the split to exist) — do not call it once per branch; call it once and branch inside `onSplit`.
- The old top-level `const split = SplitText.create(...)` + separate `gsap.from(split.words, ...)` + `return () => split.revert()` pattern is removed. `SplitText.create()`'s return value (the `SplitText` instance, needed for the cleanup `.revert()` call) is still captured at the outer level — assign it to a variable when calling `SplitText.create()` so the `mm.add()` callback can still `return () => splitInstance.revert()` for cleanup on media-query change/unmount. Per the docs, returning a tween from `onSplit()` causes GSAP to auto-revert the previous tween and preserve `totalTime()` on re-split — this is separate from and does not replace the outer `split.revert()` cleanup already present in this file for `gsap.matchMedia()`'s own teardown.
- Do not touch `Reveal.tsx` in this task — its fix is structural (Task 2), not per-component.
